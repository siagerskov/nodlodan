# Projektregler

- Bevara sortiment vid saldo 0, minimiantal, 60 dagars datumvarning och årlig lagerkontroll.
- Lokal lagring och statisk PWA är huvudspåret. Inför inte backend utan användarbeslut.
- Ändra beteende tillsammans med regressionstester, dokumentation och CHANGELOG.
- Kör `npm test` före leverans. Inga npm-beroenden behöver installeras.
- Lagra aldrig hemligheter, verkliga lagerregister eller privata säkerhetskopior i repositoryt.
- Rapportera mocktester separat från verifiering i webbläsare och fysisk iPhone.
- Publicera inte eller ändra externa konton utan användarens instruktion.
